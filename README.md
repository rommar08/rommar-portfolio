# Rommar T. Samonte - Portfolio (Next.js + Tailwind + Framer Motion)

1. npm install
2. npm run dev   ->  http://localhost:3000
3. Contact form: copy .env.local.example to .env.local and paste your free Web3Forms key
   (web3forms.com, use rommarsamonte08@gmail.com). Without a key, Send Message opens your email app.

Files you can swap: public/images/pfp.png (background-removed PNG), the four school logos,
certificate.jpg, and public/Rommar_Samonte_Resume.pdf. Awards: add paths to AWARDS in app/page.js.
Deploy: push to GitHub and import into Vercel.
